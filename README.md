# 积分兑换商城 · GitHub Pages 静态展示版

> 面向**在线预览/展示**的只读版本。无需服务器、无需数据库，推送到 GitHub 即可通过网页访问。

---

## 一、这个版本能做 / 不能做什么

| 能力 | 静态展示版 | 完整服务端版 |
|---|:---:|:---:|
| 浏览礼品列表、分类筛选、搜索 | ✅ | ✅ |
| 礼品详情弹窗 | ✅ | ✅ |
| 首页公告展示 | ✅ | ✅ |
| 用户登录 | ❌ | ✅ |
| 积分余额显示 | ❌ | ✅ |
| 积分兑换、下单 | ❌ | ✅ |
| 订单追踪、收货地址、积分明细 | ❌ | ✅ |
| 管理后台（礼品/分类/公告/用户维护） | ❌ | ✅ |

**为什么有这些限制**：GitHub Pages 只能托管静态文件，无法运行 Node.js 服务端，也连不到 MySQL。
本包的数据是在打包时从数据库**导出成 JSON 快照**放进来的，属于"某一时刻的截图"，不会随后台改动自动变化。

需要完整功能请用服务端版本部署到自己的服务器。

## 二、部署步骤（约 3 分钟）

### 第 1 步：创建仓库

在 GitHub 新建仓库（例如 `points-mall`），**可见性选 Public**（Pages 免费版需要公开仓库）。

### 第 2 步：上传文件

把本压缩包**解压后的全部内容**（`index.html`、`css/`、`js/`、`data/`、`uploads/`、`site.config.js`、`README.md`）
拖到仓库根目录上传，或者用命令行：

```bash
git init
git add .
git commit -m "首次提交：积分商城静态展示版"
git branch -M main
git remote add origin https://github.com/你的用户名/points-mall.git
git push -u origin main
```

> ⚠️ **不要上传 `site.config.js` 之外的内容**。本包已剔除服务端目录与数据库配置，不含任何密码，可安全公开。

### 第 3 步：开启 Pages

进入仓库 **Settings → Pages**，在 Build and deployment 下：

- **Source**：选 `Deploy from a branch`
- **Branch**：选 `main`，目录选 `/ (root)`
- 点 **Save**

等待约 1 分钟，页面顶部会显示访问地址。

### 第 4 步：验证

打开 `https://你的用户名.github.io/points-mall/`，确认：

- [ ] 首页礼品卡片正常显示（应为 16 件）
- [ ] 礼品图片能加载（若图片全部不显示，多半是 `uploads/` 没传上去）
- [ ] 点击礼品能弹出详情，按钮显示「演示版 · 暂不支持兑换」
- [ ] 页脚显示「静态展示版（只读快照）」
- [ ] 右上角**没有**登录按钮（静态版已自动隐藏）

## 三、常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 打开是 404 | Pages 未就绪或分支选错 | 等 2 分钟；确认 Settings → Pages 分支为 `main`、`/ (root)` |
| 页面空白 / 礼品不显示 | `data/` 目录没上传 | 检查仓库根目录有 `data/gifts.json` 等三个文件 |
| 图片全部裂图 | `uploads/` 目录没上传 | 检查仓库有 `uploads/` 及其中的图片文件 |
| 中文全乱码 | 文件被转存为 GBK | 重新上传，确保文件保持 UTF-8 编码 |
| 浏览器控制台报 `site.config.js 404` | 该文件未上传 | 它是静态模式开关，必须存在 |

## 四、如何更新礼品数据

静态版数据是**打包时的快照**。在服务端版本后台改动礼品后，需要重新导出：

```bash
# 1. 从数据库重新导出为 JSON（生成 data/ 下的三个文件）
node server/export-static.js

# 2. 重新打包
node scripts/build-ghpages.js

# 3. 把新包内容覆盖提交到 GitHub
```

提交后 Pages 会在 1～2 分钟内自动更新。

## 五、包内文件说明

| 路径 | 作用 |
|---|---|
| `index.html` | 商城首页（唯一页面） |
| `css/style.css` | 轻奢风样式 |
| `js/meta.js` | 分类/图标元数据 |
| `js/api.js` | 数据层。静态模式下改为读取 `data/*.json` |
| `js/app.js` | 页面逻辑 |
| `data/*.json` | 礼品 / 分类 / 公告的数据快照 |
| `uploads/` | 礼品图片 |
| `site.config.js` | **静态模式开关**，删除后前端会尝试请求 API（本地服务端部署用） |

## 六、安全说明

本包**不含**以下内容，可安全推送到公开仓库：

- ❌ `server/` 服务端代码（含数据库连接逻辑）
- ❌ `db.config.json` 数据库凭据
- ❌ `node_modules/` 依赖目录
- ❌ 用户数据、订单、会话令牌

生成的 zip 体积约几百 KB，仅包含前端静态资源与脱敏后的商品展示数据。
